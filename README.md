# 📱 Дозвон — крутилка красивых номеров телефонов

Telegram-бот и мини-приложение по ТЗ «три бота с круткой», первый бот — **«Телефоны»**.
Крутишь, выпадает номер с узором (777-77-77, лесенки, зеркала), собираешь коллекцию,
продаёшь дубли, крутишь дальше. «Дозвон» — рабочее название, его легко поменять.

Ядро общее: на нём потом делаются «Гараж» (машина + госномер) и «Скины».

## Что уже работает

| Раздел | Что есть |
|---|---|
| **Играть** | Спин ×1/×5/×10, обычный (100 монет) и премиум (500, сразу от Редкого). Энергия: 1 бесплатный спин раз в 3 часа, копится до 3. Выбор страны: Россия, Казахстан, Беларусь, ОАЭ. Барабаны цифр как на табло, кнопка «Пропустить», эффекты и вибрация по ступени |
| **Сегодня** | Подарок дня (серия 7 дней), колесо дня с видимыми шансами, 3 задания в день |
| **Коллекция** | Сетка 3 колонки, фильтры по ступени, поиск по узору («777»), избранное, «Продать пачкой» с итоговой суммой |
| **Рынок** | Витрина и покупка у игроков за монеты (вилка 50–150%, комиссия 10%, лот 3 дня, новый аккаунт торгует через 24 ч), мои лоты, сделки, **5 в 1**, **апгрейдер** (шанс = ставка ÷ цель × 0,85, запчасти 10%, +3% после неудачи, 10 в сутки) |
| **Друзья** | Рефссылка, друг получает 3 спина, награда пригласившему после 10 спинов друга, ступени наград 1/5/10/25, рейтинг среди друзей и общий |
| **Ещё** | Профиль и уровень, витрина из 3 лучших, магазин за Stars, настройки («всегда быстро», «без эффектов», «без апгрейдера»), шансы, история 20 операций, условия |
| **Бот** | `/start` с кнопкой игры, `/terms`, `/paysupport` (пересылает админу), уведомления «спин готов» (не больше 2 в сутки, не с 21:00 до 8:00 МСК) |
| **Админка** | `/stats` (игроки, спины, экономика, Stars), `/broadcast`, `/give`, `/reply`, `/refund`, `/config` и `/setconfig` — шансы, цены и награды меняются без выкладки кода |

### Честность и защита (из ТЗ)

- Дроп решает только сервер: ступень выбирается первой, номер собирается под неё и проверяется классификатором. Каждый дроп хранится с зерном генератора и версией шансов.
- Гарантия: Эпик и выше не позже 40-го спина подряд, Легендарный и выше не позже 200-го.
- Каждый запрос мини-приложения проверяется подписью Telegram (`initData`), есть лимит частоты и защита от двойного нажатия.
- Шансы видны до спина, барабаны останавливаются там, где решил сервер, без «почти выпало».
- Чёрный список сочетаний (1488, 228, 420, 69). Все номера помечены «игровой номер».
- Средний возврат спина 90%: остальное — слив валюты, чтобы монеты не обесценивались.

## 💰 Заработок

Монеты не продаются и не выводятся (так экономика остаётся закрытой). Платное — только
**попытки и удача за Telegram Stars**, с лимитами из ТЗ: не больше 500 ⭐ в месяц на игрока,
запас попыток до 100, не больше 50 купленных попыток в сутки, удача ×2 не чаще 3 раз в сутки.

| Товар | Цена | Бот получает (≈1,11 ₽ за ⭐) |
|---|---|---|
| Попытки ×5 / ×20 / ×50 | 25 / 89 / 199 ⭐ | ≈ 28 / 99 / 221 ₽ |
| Удача ×1,5 / ×2 на 10 спинов | 29 / 49 ⭐ | ≈ 32 / 54 ₽ |

Магазин **выключен по умолчанию** (`STARS_ENABLED=0`): ТЗ требует юридической проверки
схемы «попытки и удача за Stars» для школьной аудитории до запуска продаж. Когда будешь готов:
`STARS_ENABLED=1`. Звёзды выводятся через Fragment в TON не раньше чем через 21 день,
а выгоднее тратить их на Telegram Ads для продвижения бота (подробно в ТЗ).

Чего в боте нет сознательно (по ТЗ): продажи монет и кейсов, вывода предметов в деньги,
рынка за Stars между игроками, наград за подписку на каналы, платных билетов.

## 🚀 Запуск

Мини-приложению нужен **https-адрес**: Telegram не откроет игру по http.
Проще всего — VPS с доменом и `docker compose`, Caddy сам получит сертификат.

1. Создай бота у [@BotFather](https://t.me/BotFather), получи токен.
2. Направь домен (например `game.example.com`) на IP сервера.
3. На сервере:

```bash
git clone https://github.com/ninetybtw/bot-tg-.git && cd bot-tg-
cp .env.example .env
# впиши BOT_TOKEN, ADMIN_IDS и WEBAPP_URL=https://game.example.com
echo "DOMAIN=game.example.com" >> .env
docker compose up -d --build
```

Бот сам поставит кнопку «Играть» в меню чата. Напиши ему `/start`.

По желанию: в BotFather `/newapp` → короткое имя (например `play`) → впиши его в
`WEBAPP_SHORT_NAME`. Тогда рефссылки вида `t.me/бот/play?startapp=r123` открывают игру сразу.

### Без Docker

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполни
python -m bot          # бот + мини-приложение на порту 8080
```

Порт 8080 нужно отдать наружу через любой HTTPS-прокси (Caddy, nginx + certbot, Cloudflare Tunnel).

### Посмотреть без Telegram

Открой адрес мини-приложения в обычном браузере — включится **демо-режим** (пометка «демо»):
вся игра работает в памяти вкладки, без сервера и без настоящих покупок.

## 🛠 Админка

`/admin` в чате с ботом (только для `ADMIN_IDS`):

- `/stats` — игроки, активные сегодня, спины и дропы по ступеням, монеты выдано/слито, Stars за месяц.
- `/broadcast` — рассылка с кнопкой «Играть».
- `/give ID монеты [попытки]`, `/reply ID текст` — ответ на обращение из `/paysupport`.
- `/refund ID_чека` — возврат звёзд через `refundStarPayment`, неиспользованное снимается.
- `/config` — пришлёт полный конфиг экономики файлом. `/setconfig {"start_coins": 300}` —
  переопределить любые ключи (шансы, цены, колесо, задания, награды). У каждой правки своя версия шансов.

## Структура

```
bot/
  __main__.py          запуск: бот, веб-сервер, напоминания
  config.py            настройки из .env
  db.py                SQLite: игроки, предметы, дропы, рынок, платежи
  web.py               API мини-приложения, проверка initData
  game/
    tiers.py           шкала 9 ступеней, шансы, удача
    phones.py          генератор и классификатор номеров
    settings.py        параметры экономики по умолчанию
    service.py         вся игровая логика
  handlers/            /start, оплата Stars, админка
webapp/                мини-приложение (HTML, CSS, JS без сборки) + демо-режим
tests/                 pytest: классификатор, экономика, лимиты, API, оплата
```

Тесты: `pip install pytest && python -m pytest`
