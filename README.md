# ✨ НикМастер — Telegram-бот красивых ников и свободных @username

Бот того же формата, что и «бот с красивыми номерами»: людям дают что-то ценное
бесплатно, а бот зарабатывает на **обязательной подписке на спонсоров (ОП)**,
**рассылках** и **рекламе в выдаче**. Вирусный рост идёт через рефералку.

Главное отличие: бот **реально выдаёт** то, что обещает. Боты, которые обещают
приз и ничего не дают, собирают жалобы, получают метку SCAM или бан от Telegram,
а рекламодатели перестают у них покупать: аудитория мёртвая и сразу отписывается.

## Что умеет бот

| Функция | Что получает пользователь |
|---|---|
| ✨ **Красивый ник** | Любой текст в 30+ стилях: `𝐍𝐢𝐜𝐤`, `𝓝𝓲𝓬𝓴`, `ℕ𝕚𝕔𝕜`, `ɴɪᴄᴋ`, `꧁༺ Nick ༻꧂`, `Н̶и̶к̶`… Нажатие копирует. |
| 🎲 **Генератор ников** | Идеи по темам: игровые, милые, дерзкие, эстетика, русские. |
| 💎 **Свободные @username** | Бот находит короткие (5–6 букв) свободные юзернеймы. Стоит 💎 кристаллы. |
| 🎁 **Бонус** | +1 💎 раз в сутки, чтобы люди возвращались. |
| 👥 **Друзья** | +3 💎 за каждого приглашённого, который прошёл ОП. |

Кристаллы 💎 тратятся на поиск @username, поэтому людям выгодно звать друзей,
а бот получает бесплатный трафик.

## 💰 Как бот зарабатывает

1. **Обязательная подписка (ОП).** Перед использованием бот просит подписаться на
   каналы спонсоров. Спонсор платит за каждого подписчика (на рынке обычно
   0,5–3 ₽ за подписчика, цена зависит от ЦА и объёма). В админке задаётся заказ,
   например 1000 подписчиков. Бот считает **только тех, кто подписался через него**
   (кто был подписан раньше, не засчитывается), и сам отключает спонсора, когда заказ
   выполнен. Админу приходит уведомление.
2. **Рассылки.** Платный рекламный пост всем «живым» пользователям, с кнопкой-ссылкой.
   В статистике видно, сколько людей не заблокировало бота: это и есть охват для
   рекламодателя.
3. **Реклама в выдаче.** Строка рекламы под каждым результатом (`/setad`). Её можно
   продавать отдельно, например посуточно.

Где искать рекламодателей: биржи и чаты закупов ОП в Telegram (поиск
«ОП бот закуп», «реклама в ботах»), Telega.in. Цена растёт с числом живых
пользователей, поэтому сначала вкладывайтесь в рост: рефералка, TikTok/Shorts
«как сделать красивый ник», взаимные ОП с другими ботами.

> Сколько вы заработаете, зависит от трафика. Сам по себе бот денег не приносит,
> это инструмент, а аудиторию нужно привести.

## 🚀 Запуск

1. Создайте бота у [@BotFather](https://t.me/BotFather) и получите токен.
2. Узнайте свой Telegram ID у [@userinfobot](https://t.me/userinfobot).
3. Настройте и запустите:

```bash
git clone <repo> && cd bot-tg-
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env      # впишите BOT_TOKEN и ADMIN_IDS
python -m bot
```

Нужен Python 3.11 или новее. База SQLite создаётся сама в `data/bot.db`.

### Docker

```bash
docker build -t nickbot .
docker run -d --name nickbot --restart unless-stopped --env-file .env -v $(pwd)/data:/app/data nickbot
```

## 🛠 Админка

Команда `/admin` (работает только для `ADMIN_IDS`):

- **📊 Статистика**: всего, живые, прошли ОП, пришли по рефссылкам, прирост за день и неделю, прогресс спонсоров.
- **📢 Спонсоры (ОП)**: добавить, включить/выключить, удалить.
- **✉️ Рассылка**: любое сообщение (текст, фото, видео) плюс кнопка-ссылка, с предпросмотром.
- **📝 Реклама в выдаче**: `/setad текст` и `/delad`.
- **🏆 Топ рефералов**.
- `/give ID 10` начисляет кристаллы.

### Как добавить спонсора

1. Добавьте бота **администратором** в канал спонсора. Иначе Telegram не даст проверить подписку.
2. `/admin` → «Спонсоры» → «Добавить», затем перешлите пост из канала (или пришлите @username / ID).
3. Пришлите ссылку для кнопки. Удобно сделать отдельную пригласительную ссылку: по ней спонсор сам увидит, сколько людей пришло от вас.
4. Укажите размер заказа (0 означает без лимита).

Если бота убрали из админов канала, этот спонсор просто пропускается, и бот не
блокирует пользователей. В логах при этом появляется предупреждение.

## Структура

```
bot/
  __main__.py        запуск, middleware, polling
  config.py          настройки из .env
  db.py              SQLite: пользователи, спонсоры, учёт подписок
  middlewares.py     регистрация, рефералка, обязательная подписка
  keyboards.py       кнопки
  utils.py           реклама в выдаче, реф-ссылки
  handlers/          start, nick, username, profile, admin, system
  services/
    fonts.py         юникод-шрифты и украшения
    nickgen.py       генератор ников по темам
    usernames.py     поиск и проверка свободных @username
tests/               тесты (pytest)
```

Тесты: `pip install pytest && python -m pytest`

## Заметки

- Свободность @username проверяется через страницу `t.me/<name>`. Юзернеймы,
  которые продаются на Fragment или зарезервированы Telegram, так не отличить,
  поэтому бот пишет «скорее всего свободен».
- Состояния диалогов (FSM) хранятся в памяти: после перезапуска незаконченный
  ввод в админке сбрасывается. Пользователи, балансы и спонсоры лежат в SQLite и
  не теряются.
- Экономику (стартовый баланс, награду за друга, бонус) меняют в `.env`. Цены
  поиска @username задаются в `FIND_COST` в `bot/keyboards.py`.
