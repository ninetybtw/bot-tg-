# 📱 Дозвон — крутилка красивых номеров телефонов

Telegram-бот и мини-приложение (ТЗ v1.4). Крутишь, на табло перекидываются цифры и выпадает
номер с узором (777-77-77, лесенки, зеркала, палиндромы), собираешь коллекцию, продаёшь лишнее,
торгуешь на рынке, улучшаешь номера. Всё решает сервер, каждый бросок можно проверить.

### Надёжность

- Деньги — целые копейки, каждое изменение баланса в журнале `ledger`, дропы и журнал только дописываются.
- Каждый запрос подписан Telegram (`initData`), у каждой покупки ключ идемпотентности: повтор не спишет дважды. Запросы одного игрока выполняются по очереди, есть лимит частоты.
- Чёрный список сочетаний (1488, 228, 420, 69). Все номера помечены «игровой номер».

## 💰 Заработок

Монеты не продаются и не выводятся. За Telegram Stars — только попытки, удача, VIP и места,
с лимитами: не больше 500 ⭐ в месяц на игрока, запас попыток до 100.

| Товар | Цена |
|---|---|
| Попытки ×5 / ×20 / ×50 | 25 / 89 / 199 ⭐ |
| Удача ×1,5 / ×2 на 10 спинов Обычной | 29 / 49 ⭐ |
| VIP 7 / 30 дней (комиссия 5%, +2 попытки в день, +10 мест) | 79 / 249 ⭐ |
| +5 мест в коллекции | 99 ⭐ |
| Набор «Старт» (один раз) | 169 ⭐ |

Магазин включается переменной `STARS_ENABLED=1` (до запуска продаж стоит проверить схему с юристом).

## 🚀 Запуск

Мини-приложению нужен **https-адрес**: Telegram не откроет игру по http.
Проще всего — VPS с доменом и `docker compose`, Caddy сам получит сертификат.

1. Создай бота у [@BotFather](https://t.me/BotFather), получи токен.
2. Направь домен (например `game.example.com`) на IP сервера.
3. На сервере:

```bash
git clone https://github.com/ninetybtw/bot-tg-.git && cd bot-tg-
cp .env.example .env
# впиши BOT_TOKEN, ADMIN_IDS и WEBAPP_URL=https://game.example.com
echo "DOMAIN=game.example.com" >> .env
docker compose up -d --build
```

Бот сам поставит кнопку «Играть» в меню чата. Напиши ему `/start`.

По желанию: в BotFather `/newapp` → короткое имя (например `play`) → впиши его в
`WEBAPP_SHORT_NAME`. Тогда рефссылки вида `t.me/бот/play?startapp=r123` открывают игру сразу.

### Без Docker

```bash
python3 -m venv .venv && source .venv/bin/activate
pip install -r requirements.txt
cp .env.example .env   # заполни
python -m bot          # бот + мини-приложение на порту 8080
```

Порт 8080 нужно отдать наружу через любой HTTPS-прокси (Caddy, nginx + certbot, Cloudflare Tunnel).

### Посмотреть без Telegram

Открой адрес мини-приложения в обычном браузере — включится **демо-режим** (пометка «демо»):
`webapp/demo.js` повторяет правила сервера в браузере (те же шансы, гарантии, тиражи и честный бросок),
номера берёт из пула настоящего генератора. Пересобрать после правки конфига:
`python scripts/build_demo_config.py`.

## 🛠 Админка

`/admin` в чате с ботом (только для `ADMIN_IDS`):

- `/stats` — игроки, активные сегодня, спины и дропы по ступеням, приток и слив по причинам, тиражи, Stars за месяц.
- `/broadcast` — рассылка с кнопкой «Играть».
- `/give ID рубли [попытки]`, `/reply ID текст` — ответ на обращение из `/paysupport`.
- `/panel` — админка страницей: кнопка для Telegram и ссылка для браузера.
- `/raffle` — провести розыгрыш дня сейчас.
- `/ad Заголовок | Текст | https://t.me/канал | Кнопка | 📣` — добавить рекламу на главный экран (до 3),
  `/ad` — что стоит сейчас и статистика (увидели, перешли, конверсия), `/ad off 2` — снять вторую, `/ad off` — все.
- `/refund ID_чека` — возврат звёзд через `refundStarPayment`, неиспользованное снимается.
- `/config` — пришлёт полный конфиг экономики файлом. `/setconfig {"start_cents": 300000}` —
  переопределить любые ключи (шансы, цены, колесо, задания, награды). У каждой правки своя версия шансов.

## Структура

```
bot/
  __main__.py          запуск: бот, веб-сервер, напоминания
  config.py            настройки из .env
  db.py                SQLite: игроки, предметы, дропы, рынок, платежи
  web.py               API мини-приложения, проверка initData
  game/
    tiers.py           шкала 9 ступеней, удача
    odds.py            мягкие гарантии и точный долгосрочный расчёт
    fair.py            честный бросок HMAC-SHA256
    phones.py          генератор и классификатор номеров
    devices.py         каталог 50 телефонов для кейса
    settings.py        параметры экономики по умолчанию
    service.py         вся игровая логика
  handlers/            /start, оплата Stars, админка
webapp/                мини-приложение (HTML, CSS, JS без сборки) + демо-режим, admin.html — админка
scripts/               сборка webapp/config.demo.js из настоящего конфига
tests/                 pytest: классификатор, экономика, лимиты, API, оплата
```

Тесты: `pip install pytest && python -m pytest`
